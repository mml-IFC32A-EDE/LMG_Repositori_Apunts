Introducció a HTML

HTML significa HyperText Markup Language.

És un llenguatge de marques que s'utilitza per crear pàgines web.

HTML permet estructurar el contingut d'una pàgina web mitjançant etiquetes.

Història d'HTML

  • 1991: Tim Berners-Lee crea HTML.
  • 1995: apareix HTML 2.0.
  • 2014: es publica HTML5.

Estructura bàsica d'un document HTML

Un document HTML té una estructura bàsica formada per diferents etiquetes.

<!DOCTYPE html>
<html>
    <head>
        <title>Títol de la pàgina</title>
    </head>

    <body>
        Contingut de la pàgina web
    </body>
</html>

Elements principals

  • <!DOCTYPE html>: indica que el document utilitza HTML5.
  • <html>: element principal del document.
  • <head>: conté informació sobre la pàgina.
  • <body>: conté el contingut visible de la pàgina.

Etiquetes bàsiques

  • <title>: defineix el títol de la pàgina.
  • <h1> fins a <h6>: defineixen encapçalaments de diferents nivells.
  • <p>: defineix un paràgraf.
  • <br>: insereix un salt de línia.
  • &nbsp;: insereix un espai en blanc que no es pot separar.

Exemple

<h1>Títol principal</h1>
<h2>Subtítol</h2>
<p>Aquest és un paràgraf.</p>
<br>
<p>Aquest text apareix després d'un salt de línia.</p>

Elements HTML

Un element HTML està format per una etiqueta d'obertura, el contingut i una etiqueta de tancament.

Exemple

<p>Aquest és un paràgraf.</p>
  • Etiqueta d'obertura: <p>
  • Contingut: Aquest és un paràgraf.
  • Etiqueta de tancament: </p>

Les etiquetes indiquen al navegador com ha d'interpretar el contingut.

Niament d'elements HTML

El niament consisteix a col·locar elements HTML dins d'altres elements.

Exemple correcte

<p>
    Aquest és un paràgraf amb
    <strong>text important</strong>.
</p>

Regla important

La primera etiqueta que s'obre és l'última que s'ha de tancar.

Les etiquetes s'han de tancar en l'ordre correcte per evitar errors en el document.

Atributs HTML

Els atributs proporcionen informació addicional sobre els elements HTML.

Atributs principals

  • id: identifica un element de manera única.
  • class: assigna una classe a un element.
  • style: permet aplicar estils directament.
  • title: proporciona informació addicional.
  • src: indica la ruta d'una imatge o recurs.
  • alt: descriu una imatge.
  • href: indica la destinació d'un enllaç.

Exemple

<p id="principal" class="text">Hola món</p>

<img src="imatge.jpg" alt="Descripció de la imatge">

<a href="https://www.google.com">Google</a>

Format de text

HTML disposa de diferents etiquetes per donar format al text.

  • <b>: mostra el text en negreta.
  • <strong>: indica que el text té importància.
  • <i>: mostra el text en cursiva.
  • <em>: dona èmfasi al text.
  • <u>: subratlla el text.
  • <strike> o <s>: mostra el text ratllat.
  • <sup>: mostra text en superíndex.
  • <sub>: mostra text en subíndex.

Exemple

<b>Negreta</b>
<i>Cursiva</i>
<u>Subratllat</u>
<s>Ratllat</s>
H<sub>2</sub>O
X<sup>2</sup>

Comentaris en HTML

Els comentaris permeten afegir notes dins del codi HTML.

No es mostren visualment a la pàgina web.

Sintaxi

<!-- Aquest és un comentari -->

Exemple

<!-- Títol principal de la pàgina -->
<h1>Benvinguts</h1>

<!-- Paràgraf de presentació -->
<p>Aquesta és la meva pàgina web.</p>

És recomanable utilitzar comentaris per organitzar i explicar el codi.
