Tipus d’entrada especials

Els tipus d’entrada especials permeten validar i mostrar els camps d’un formulari de manera més adequada segons el tipus de dades que s’espera obtenir de l’usuari.

  • password: contrasenya.
  • email: correu electrònic.
  • url: adreça web.
  • tel: número de telèfon.
  • number: valor numèric.
  • range: valor dins d’un interval.
  • date: data.
  • time: hora.
  • datetime-local: data i hora local.
  • month: mes.
  • week: setmana.
  • color: color.
  • file: fitxer.
