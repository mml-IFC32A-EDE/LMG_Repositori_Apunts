Introducció a HTML

HTML (HyperText Markup Language) és el llenguatge de marques que s’utilitza per crear pàgines web.

Defineix l’estructura de la pàgina mitjançant etiquetes que el navegador interpreta per mostrar el contingut.

Breu història:

  • Creat per Tim Berners-Lee l’any 1991.
  • HTML 2.0 (1995): primer estàndard oficial.
  • HTML5 (2014): versió amb noves funcionalitats, com suport per a vídeo, àudio i gràfics.
