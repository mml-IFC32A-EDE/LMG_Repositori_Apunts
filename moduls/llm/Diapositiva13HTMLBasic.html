Llistes en HTML

  • Llistes no ordenades (<ul>): s’utilitzen quan l’ordre dels elements no és específic. Els elements es mostren amb vinyetes o altres símbols. Cada element es defineix amb <li>.
  • Llistes ordenades (<ol>): s’utilitzen quan l’ordre dels elements és rellevant. Els elements es numeren automàticament i també es defineixen amb <li>.
