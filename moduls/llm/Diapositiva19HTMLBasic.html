Tasca: currículum

L’activitat proposa crear una pàgina web personal que contingui el currículum vitae (CV) utilitzant els conceptes apresos durant el curs bàsic d’HTML.

L’objectiu és aplicar elements com encapçalaments, llistes, taules, enllaços, imatges, comentaris i atributs bàsics.

Els currículums solen seguir una organització clara i seqüencial, destacant primer els apartats més rellevants segons el perfil del candidat.

  • Informació personal
  • Resum professional
  • Experiència laboral
  • Educació i formació
  • Habilitats tècniques
  • Habilitats
  • Idiomes
  • Certificacions i cursos
  • Enllaços d’interès, com LinkedIn o GitHub
  • Certificacions tècniques o cursos especialitzats
