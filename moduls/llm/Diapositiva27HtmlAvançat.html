Etiqueta template

L’etiqueta <template> defineix fragments HTML reutilitzables que no es mostren immediatament quan es carrega la pàgina.

El contingut de <template> no s’afegeix al document fins que es manipula explícitament amb JavaScript. Això permet crear plantilles que es poden clonar i inserir al DOM de manera dinàmica.

És útil per preparar estructures HTML que es podran afegir al document en temps real sense que siguin visibles inicialment.

  • Mantingues les plantilles simples i modulars.
  • Clona les plantilles amb JavaScript per controlar quan i com s’afegeixen al DOM.
  • Utilitza plantilles per generar contingut dinàmicament, com llistes o targetes de productes.
  • No incloguis contingut actiu dins del template esperant que s’executi abans d’afegir-lo al DOM.
