Etiqueta iframe

<iframe> (inline frame) és una etiqueta HTML que permet inserir una pàgina HTML dins d’una altra pàgina web.

Permet incrustar contingut extern, com altres pàgines web, vídeos, formularis o mapes, dins d’una pàgina principal.

S’utilitza sovint per a continguts dinàmics, com vídeos de YouTube, Google Maps o integracions de serveis externs.

Es pot personalitzar amb atributs com width, height, src i frameborder.

  • Evita l’ús excessiu d’iframes perquè poden alentir la pàgina i fer-la més difícil de gestionar.
  • Utilitza l’atribut sandbox per limitar les accions que pot realitzar el contingut incrustat.
  • Optimitza l’alçada i l’amplada per a diferents mides de pantalla.
  • Considera alternatives quan puguis carregar directament el contingut.
  • Utilitza allowfullscreen quan vulguis permetre la visualització de vídeos a pantalla completa.
