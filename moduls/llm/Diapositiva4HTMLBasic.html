Estructura bàsica d’un document HTML

Un document HTML es basa en una estructura jeràrquica d’etiquetes que defineixen les diferents parts d’una pàgina.

Cada pàgina HTML segueix una estructura similar: comença amb <!DOCTYPE> i continua amb les etiquetes <html>, <head> i <body>.

  • <!DOCTYPE html>: indica el tipus de document HTML.
  • <html>: element principal que conté tot el document.
  • <head>: conté informació sobre el document.
  • <body>: conté el contingut visible de la pàgina.
