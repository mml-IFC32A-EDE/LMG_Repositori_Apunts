Atributs HTML

Els atributs en HTML són elements que afegeixen informació extra a les etiquetes per modificar-ne el comportament o l’aparença.

Els atributs es col·loquen dins de l’etiqueta d’obertura i segueixen el format nom="valor".

  • id: identifica un element de manera única.
  • class: assigna una classe a un element.
  • style: permet definir estils en línia.
  • title: proporciona informació addicional.
  • src: indica la ruta d’un recurs, com una imatge.
  • alt: proporciona un text alternatiu per a una imatge.
  • href: defineix la destinació d’un enllaç.
