Eines inicials: Sublime Text

Sublime Text és un editor de codi lleuger i multiplataforma, disponible per a Windows, macOS i Linux. Està orientat a la velocitat i l’eficiència.

El seu nucli està escrit en C++ i disposa d’una API de connectors en Python.

  • Funcions clau: Goto Anything, Command Palette, múltiples cursors i seleccions en columnes, mode Distraction Free, minimapa, edició en columnes i panells, cerca i reemplaçament amb expressions regulars, fragments de codi (snippets), macros i sistemes de compilació configurables.
  • Es pot ampliar mitjançant paquets, gestionats habitualment amb Package Control.
  • La llicència és comercial, amb prova indefinida; és programari tancat.
  • Punts forts: rapidesa, baix consum, estabilitat amb fitxers grans i un alt nivell de personalització.
